# きろくカレンダー

服薬・日々のメモ（写真/動画添付）・お仕事のシフト（時給制）や出勤（月給制）と給与を1つのカレンダーで記録できる、個人用のWebアプリです。ビルド不要で、GitHub Pagesにそのまま公開できます。スマートフォンのホーム画面にアプリのように追加することもできます。

## 主な機能

- **記録モード**
  - カレンダーから日付を選んで、登録した薬ごとに服薬（服薬した／しなかった／未記録の3状態）を個別に記録
  - その日のメモは「＋ メモを追加」で何個でも増やせる。メモ1つごとに自由記述のテキストと、画像・動画を複数添付可能（例：朝の記録と夜の記録を別々のメモとして分けて書ける）
  - 添付した写真・動画はそれぞれ独立した枠で表示され、1枚ごとに個別のコメントを書き込める（例：写真Aには「ラーメン」、写真Bには「デザート」）。メモを削除すると、そのメモに添付した写真・動画だけがまとめて削除される（他のメモの内容には影響しません）
  - 写真をタップすると画面中央に大きく表示され、ピンチ操作（またはダブルタップ／マウスホイール）で拡大・縮小、拡大中はドラッグで表示位置を移動できる
  - お仕事の設定（勤務先名・色、「時給制」または「月給制」、交通費や食事補助などの手当）を登録し、日付ごとに勤務を記録。会社員などの月給制にも対応しています
  - 時給制は開始〜終了・休憩時間を登録すると時給×時間で自動計算。月給制は時刻の入力は不要で「出勤した」を記録するだけでよく、その月に1回でも出勤記録があれば、その月の給与として基本給が計上されます（複数回記録しても2倍にはなりません）
  - 登録済みの勤務先は「編集」からいつでも内容を変更可能（すでに記録した月の給与は、変更時点の内容のまま残ります。時給制⇔月給制の切り替えも可能で、切り替え前の設定も保持されます）
  - 勤務先に「いつものシフト時間」を設定しておくと（時給制のみ）、シフト登録時にその勤務先を選ぶだけで開始・終了・休憩時間が自動入力される
  - 表示中の月の給与を自動集計（勤務先ごとの内訳つき）。手当は行ごとに「月1回」（その月に出勤が1回でもあれば1回だけ）か「出勤ごと」（記録1件につき毎回）を選んで加算できる
  - カレンダー一覧から、メモや服薬記録のある日・勤務のある日がドット表示でひと目でわかる
  - お仕事をしていない方向けに、設定画面の「お仕事の記録を使う」をオフにすると、カレンダーやメモの画面からお仕事関連の表示（給与サマリー・凡例・記録欄など）をまとめて隠せます。登録済みの勤務先や記録は消えず、オンに戻せばそのまま復活します
  - 過去・未来どの日付にも自由に記録可能（年月はプルダウンで一気にジャンプ可）
- **閲覧モード**
  - 記録のある日を新しい順にカード表示し、TLのようにスクロールでどんどん過去に遡って読み込み
  - カードから直接「編集」で記録モードの該当日を開ける
- **バックアップ**
  - 右上のアイコンから、全データ＋添付ファイルをZIPとして書き出し／読み込み可能
  - 機種変更やブラウザの変更前にエクスポートしておくことを推奨
- **テーマのカスタマイズ**（設定 ⚙️ から）
  - サイト全体のアクセントカラーをプリセットの8色、またはカラーピッカーで自由な色に変更可能（ボタンや今日の日付の枠などに反映されます）
  - 服薬・危険・シフトなど、意味を持たせている個別の色はわかりやすさのため変更されません
  - 表示を「端末に合わせる」「ライト」「ダーク」から選択可能（「端末に合わせる」を選ぶと、スマートフォンやブラウザ側のダークモード設定に自動で追従します）
  - どんな色を選んでも、ボタンの文字が読みにくくならないよう自動的に白文字／濃い文字が選ばれます
  - 「初期設定に戻す」でいつでも元の色・表示設定に戻せます
- **薬の在庫管理**（設定 ⚙️ から）
  - 薬ごとに名前・残量・1日の服用数を登録すると、なくなる目安の日付を自動計算
  - 記録モードでは薬ごとに個別のチェックボタンが並び、それぞれ独立して「服薬した／しなかった」を記録可能（薬Aは飲んだが薬Bは飲んでいない、といった記録もできます）
  - 設定画面で薬ごとに「飲むタイミング」（朝・昼・夜・寝る前など、自由入力も可）を登録すると、記録モードではタイミングごとに個別のチェックボタンが並ぶようになる（朝は飲んだが夜は忘れた、といった記録も可能）
  - タイミングを設定した薬は、設定画面に直近30日の時間帯ごとの服薬率が表示され、一番飲み忘れが多い時間帯が自動でハイライトされる
  - カレンダーで薬ごとに「服薬した」と記録した日の分だけ、その薬の実際の残量から自動で減っていく（記録がない日・「服薬しなかった」の日はカウントされません。タイミングを設定した薬は、服用数をタイミングの数で均等に割った分だけ、実際にチェックしたタイミングの分だけ減ります）
  - 設定画面では「現在の残量（目安）」が大きく表示され、ひと目で今どれくらい残っているかが分かる（登録時に入力した基準値は「▸ 基準値を修正する」を開いたときだけ表示され、普段は目に入らない）
  - 残量はいつでも書き換え可能（書き換えた時点を基準日として再計算）
  - 残り7日分以下になると、現在の残量の表示が警告色に変わり、記録モードの上部にも自動で注意バナーを表示
- **ホーム画面への追加（PWA対応）**
  - スマートフォンのホーム画面にアイコンを追加して、アプリのように起動できます
  - オフラインでも（電波が無い状態でも）開けるようキャッシュされます

## ホーム画面に追加する方法

GitHub Pagesなどで公開したURL（`file://`で直接開いた場合は対象外）にスマートフォンでアクセスし、以下の操作を行ってください。

- **iPhone（Safari）**：共有ボタン（□に↑のアイコン）→「ホーム画面に追加」
- **Android（Chrome）**：右上の「⋮」メニュー→「ホーム画面に追加」／「アプリをインストール」

追加すると、ブラウザのアドレスバーなどが表示されない全画面のアプリのような見た目で起動します。

## データの保存について

このアプリはサーバーを持たず、すべてのデータは**閲覧しているブラウザ内（IndexedDB）にのみ**保存されます。

- メリット：個人情報が外部サーバーに送信されない、オフラインでも動作する
- 注意点：別のブラウザ・別の端末からは同じデータを見られません。ブラウザのデータを消去すると記録も消えるため、定期的に「バックアップ」からのエクスポートをおすすめします

## ファイル構成

```
index.html               アプリ本体（HTML/CSS/JSすべてここに内包）
manifest.json            ホーム画面追加用のWebアプリマニフェスト
sw.js                    オフラインキャッシュ用のService Worker
icons/
  icon-192.png           ホーム画面アイコン（192×192）
  icon-512.png           ホーム画面アイコン（512×512・maskable兼用）
  apple-touch-icon.png   iOS用アイコン（180×180）
README.md                このファイル
```

これらをすべて同じ階層に置いてください（`manifest.json` や `sw.js` を別の場所に移動すると、ホーム画面への追加やオフライン動作が機能しなくなります）。

## GitHub Pagesへの公開方法

1. このリポジトリのファイル一式をリポジトリ直下（または `/docs` フォルダ）に、上記のファイル構成を保ったまま置く
2. GitHubのリポジトリ設定 → **Settings > Pages** で、公開元のブランチとフォルダを指定する
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

※ Service WorkerはHTTPS（またはlocalhost）でのみ有効になります。GitHub Pagesは自動的にHTTPSになるため、公開後は追加の設定なしでホーム画面への追加・オフライン動作が有効になります。

## ローカルでの動作確認

`index.html` をブラウザで直接開いても動作しますが、簡易サーバー経由で確認するのがおすすめです。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

## 技術構成

- HTML / CSS / JavaScript（ES Modules）のみ。ビルド工程なし
- PWA対応：`manifest.json` + `sw.js`（Service Worker）でホーム画面への追加とオフライン起動に対応
- データ保存：IndexedDB（`entries` / `media` / `jobs` / `medications` / `settings` の5ストア）
- バックアップ機能用に [JSZip](https://stuk.github.io/jszip/)（MITライセンス）を `index.html` 内に直接埋め込み。外部CDNに依存せず、オフラインでも読み込みに失敗しません
- 見出し・数字の一部にGoogle Fonts「Zen Maru Gothic」を使用（読み込めない環境では自動的にシステムフォントにフォールバック）
- ダークモード（`prefers-color-scheme`）に対応
